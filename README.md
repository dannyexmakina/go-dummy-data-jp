# dummy-data-jp

日本の氏名・住所などのダミーデータを TSV で生成する CLI
JIS X 0208・MJ 文字・人名用漢字などを使い、文字コードや文字数の上限に近いデータでのテストを想定

## 出力項目

| 列 | 内容 |
| --- | --- |
| 氏 / 名 | 氏は MJ 文字、名は人名用漢字・ひらがな・カタカナから生成（`--alpha` で全角英数字） |
| 氏カナ / 名カナ | カタカナ（氏名合計 40 文字以内） |
| 年齢 | 0〜125。年齢分布に応じた重みづけ |
| 性別 | 男性 / 女性（`--unanswered` で「未回答」を含める） |
| 電話番号 | 市外局番＋連番、または 50% の確率で携帯・IP電話の局番 |
| 郵便番号 | 都道府県内からランダムに選択 |
| 都道府県 | 人口比に応じた重みづけ |
| 住所1 | 市区町村＋小字相当＋番地（100 文字以内） |
| 住所2 | 建物名など。20% の確率で空欄（100 文字以内） |

## 使い方

```sh
task build                # build/dummy-data-jp を生成
./build/dummy-data-jp -n 100 -o out.tsv
```

または `go run ./cmd -n 5`。

### オプション

| フラグ | 説明 |
| --- | --- |
| `-n, --number` | 生成件数（既定 10） |
| `-o, --output` | 出力先ファイル（省略時は標準出力） |
| `--no-header` | ヘッダ行を出力しない |
| `--alpha` | 氏名を全角英数字から生成する |
| `--extended-mj` | IVS・CJK 拡張漢字など標準フォントで表示できない MJ 文字を含める |
| `--unanswered` | 性別に「未回答」を含める |
| `--min-age` / `--max-age` | 年齢の範囲（0〜125） |

## 生成方法

| 項目 | 抽出・選出方法 |
| --- | --- |
| 氏 | 1〜4 文字（5% / 80% / 14% / 1%）。90% を常用漢字、10% をその他の MJ 文字から選ぶ |
| 名 | 文字数は氏と同様。人名用漢字・ひらがな・カタカナの合算集合からランダムに選ぶ |
| `--alpha` 時の氏名 | 氏名合計で上限の 205 文字以下とする。氏の文字数を 1〜204、名の文字数を 1〜（205 − 氏の文字数）からそれぞれランダムに選ぶ。文字は全角英数字・ギリシャ文字などからランダムに選ぶ |
| 氏カナ / 名カナ | それぞれ 1〜8 文字のカタカナをランダムに選ぶ |
| `--alpha` 時の氏名カナ | 氏名合計で上限の 40 文字以下とする。氏の文字数を 1〜39、名の文字数を 1〜（40 − 氏の文字数）からそれぞれランダムに選ぶ |
| 年齢 | 年齢別人口の累積比率表からランダムで選ぶ。`--min-age` / `--max-age` 指定時は範囲内の年齢のみを対象とし、累積比率を使ってランダムに選ぶ |
| 性別 | 男性 / 女性から等確率で選ぶ。`--unanswered` 指定時は男性 / 女性 / 未回答から等確率で選ぶ |
| 都道府県 | 人口の比率からランダムで選ぶ |
| 郵便番号 | 選んだ都道府県の郵便番号データからランダムに 1 件選ぶ |
| 電話番号 | 50% で郵便番号データの市外局番、残りは 090 / 080 / 070 / 050。以降の桁は 99999999999 から減算する連番（重複しない） |
| 住所1 | 都道府県名＋郵便番号データの町域名＋（50% で MJ 文字・かな 2〜4 文字の小字相当）＋番地（`０００` または `０―００―００`） |
| 住所2 | 20% で空欄。残りは MJ 文字・かな・記号から 1〜30 文字 |

- 先頭の文字に小書きのかな（ぁ・っ・ャ など）は使わない
- MJ 文字は標準フォントで表示できるものに限る（`--extended-mj` で IVS・CJK 拡張漢字も含める）

## 開発

要件: Go 1.26 / [Task](https://taskfile.dev/)

```sh
task build       # 現在の環境向けにビルド
task build:all   # darwin / linux / windows 向けにクロスビルド
task vet         # go vet と gofmt チェック
task run -- -n 5 # 実行
task clean       # ビルド成果物を削除
```
