# dummy-data-jp

日本人の氏名・住所などのダミーデータを TSV で生成する CLI
JIS X 0208・MJ 文字・人名用漢字などを使い、文字コードや文字数の上限に近いデータでのテストを想定

## 出力項目

| 列 | 内容 |
| --- | --- |
| 氏 / 名 | 氏は MJ 文字、名は人名用漢字・ひらがな・カタカナから生成（`--alpha` で全角英数字） |
| 氏カナ / 名カナ | カタカナ（氏名合計 40 文字以内） |
| 年齢 | 0〜125。年齢分布に応じた重みづけ |
| 性別 | 男性 / 女性（`--unanswered` で「未回答」を含める） |
| 電話番号 | 市外局番＋連番、または 50% の確率で携帯・IP電話の局番 |
| 郵便番号 | 都道府県内からランダムに選択 |
| 都道府県 | 人口比に応じた重みづけ |
| 住所1 | 市区町村＋小字相当＋番地（100 文字以内） |
| 住所2 | 建物名など。20% の確率で空欄（100 文字以内） |

## 使い方

```sh
task build                # build/dummy-data-jp を生成
./build/dummy-data-jp -n 100 -o out.tsv
```

または `go run ./cmd -n 5`。

### オプション

| フラグ | 説明 |
| --- | --- |
| `-n, --number` | 生成件数（既定 10） |
| `-o, --output` | 出力先ファイル（省略時は標準出力） |
| `--no-header` | ヘッダ行を出力しない |
| `--alpha` | 氏名を全角英数字から生成する |
| `--extended-mj` | IVS・CJK 拡張漢字など標準フォントで表示できない MJ 文字を含める |
| `--unanswered` | 性別に「未回答」を含める |
| `--min-age` / `--max-age` | 年齢の範囲（0〜125） |

## 開発

要件: Go 1.26 / [Task](https://taskfile.dev/)

```sh
task build       # 現在の環境向けにビルド
task build:all   # darwin / linux / windows 向けにクロスビルド
task vet         # go vet と gofmt チェック
task run -- -n 5 # 実行
task clean       # ビルド成果物を削除
```
